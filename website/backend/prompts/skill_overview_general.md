## Skill 概要

**General Optimization**（原始 Skill：`or-general-solver`）是通用型的作業研究解題手冊：把文字敘述的 OR 問題，經過三道明確的關卡——**問題理解、數學建模、錯誤防護**——再精確求解與驗證，最後寫成 7 段結構化的解答。

與另外兩個 Skill 的差別：Concept Identification 著重**辨認模型結構**（ORQA 選擇題），Practical Implementation 著重**LP / IP 數值求解**；General Optimization 涵蓋的題型最廣，並且強調**錯誤防護**與**依證據標示答案狀態**。

## 為什麼需要這份 Skill

OR 題目答錯，很少是因為數學太難，多半來自三個地方：

1. **理解錯誤**：回答了「類似的教科書題目」而不是題目本身，例如漏掉規則、目標方向相反、題目要方案卻只給數值。
2. **建模錯誤**：限制式方向寫反、邏輯條件寫錯、變數型態（連續／整數／0-1）判斷錯。
3. **宣稱過頭**：沒有證明卻說「最佳解」，或宣稱跑過求解器、程式。

## 解題流程

| 階段 | 內容 |
|---|---|
| 1. 問題理解 | 決策、目標與方向、題目要的答案、資料表（含單位）、規則清單 R1…Rn（含隱含規則）、題型與假設 |
| 2. 數學建模 | 變數型態判斷、每條限制式都對應到一條規則（可追溯）、文字轉數學、模型類型 |
| 3. 錯誤防護 | 核心檢查 G1–G4（目標、規則覆蓋、方向與邏輯、變數型態），依情況加上單位、資料索引、比例、Big-M、平衡式、可行性預檢、題型陷阱 |
| 4. 選擇方法並求解 | 依模型複雜度選擇能手算完成、且能提供證明的最強方法 |
| 5. 驗證與狀態 | 代回檢查、重算目標值、最佳性證據，並標示答案狀態 |

## 答案狀態標示

| 狀態 | 意義 |
|---|---|
| 已證明為最佳解 | 可行，且有有效的最佳性證明（完整列舉、上下界相等、對偶等） |
| 目前最佳候選解 | 可行，但尚未證明最佳 |
| 無可行解 | 有證明沒有任何解滿足所有限制 |
| 目標函數無界 | 有證明目標可以無限改善 |
| 僅完成建模 | 只建立模型，說明原因與適合的求解方法 |

## 涵蓋題型

LP、IP、MILP（專案選擇、背包、固定成本、邏輯條件）、生產組合、混合、飲食、運輸、指派、網路流、最短路徑、最小生成樹、TSP、CPM / PERT、排程、多期存貨、EOQ 與報童模型、等候線、決策分析、賽局、馬可夫鏈、動態規劃、非線性最佳化。

## 在本網頁中的使用方式

這份 Skill 本來就是為自由提問設計，並自帶 7 段輸出格式，因此本網頁只加上很短的使用說明：沿用 Skill 自己的格式（問題理解、模型元素、數學模型、錯誤防護、求解過程、驗證、結論），並以網頁共用的格式規則（語言、Markdown、LaTeX、不執行程式）為優先。

Skill 的原始內容沒有被修改；可在後端 `config.yaml` 的 `prompts.skills` 中新增或替換 Skill。
